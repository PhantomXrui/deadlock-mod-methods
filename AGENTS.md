# Methods-only repository

Document two distinct routes: custom-character transplantation and original-game-skin recoloring. Prioritize how Codex implemented the pipeline, actual build attempts, failures, evidence, bounded fixes, and verification. Do not turn this repository into a separate mouse-click manual.

Use local scripts and reports as evidence, but summarize their technical findings rather than copying private chats, machine paths or whole projects. Mark historical results and unverified conclusions accurately.

Public files may contain text, short explanatory code snippets, reusable instructions, diagrams and user-authorized process pictures: model renders, in-game result screenshots and tool interfaces. Keep reviewed pictures under assets/images, remove private paths and text/EXIF metadata, and label their historical stage and verification limits. Never publish chat screenshots, models, raw game textures, compiled resources, VPKs, executables, installers, tool source bundles or project archives. Provide upstream links for tools. A screenshot does not grant rights to the depicted model or software.

Do not run builds, alter game installation, edit original models, or publish assets merely because this documentation describes those actions. Follow the current user task. Preserve unrelated active projects and local working changes.
